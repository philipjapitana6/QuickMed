## ✨ Core Features & Specialties

* **🩺 Online Doctor Appointments:** Browse verified medical practitioners filtered by specialty (Cardiology, Neurology, Pediatrics, Pulmonology, and more) with visible license numbers and easy appointment scheduling[cite: 2, 3, 5].
* **🛏️ Hospital & Room Locator (Online Admittance):** Check real-time vacant and occupied hospital room counts, addresses, and direct contact numbers across Iloilo hospitals (such as WVMC and QualiMed)[cite: 2, 3, 4].
* **💬 Confidential Patient-Doctor Chat:** Communicate privately and securely with healthcare professionals regarding consultations and patient records[cite: 2, 3].
* **🚨 SOS Distress Signal with GPS Navigation:** Instant-access emergency SOS bar equipped with real-time GPS tracking navigation for rapid medical response[cite: 2, 3, 4, 5].
